# Phase 0 — Exit Criteria

Phase 0 is complete when the following are agreed:

- [ ] Product brief and intended users approved.
- [ ] Ferrari SF-24 / #16 confirmed as the initial study reference (not a claim of exact CAD fidelity).
- [ ] Visual design direction and colour/type tokens approved.
- [ ] Global workstation layout approved.
- [ ] Explorer, Inspector, Exploded, Disassembly, Assembly and Engineering workspaces reviewed.
- [ ] Hover, selection, isolation, section, explode, remove, place, invalid and success states specified.
- [ ] Component identity, hierarchy, interfaces and dependencies model defined.
- [ ] Asset source, licensing and fidelity strategy agreed.
- [ ] Engineering data provenance and model-validation policy agreed.

## Next step after approval
Create the Phase 1 technical prototype: application shell, viewport, camera controls and an original/licensed segmented vehicle asset. Do not build the full simulator in one pass.
